## About This Project

This repository contains my learning progress, practical exercises, executed notebooks, quiz results, and summaries while completing the Hugging Face Large Language Models (LLM) Course.

The purpose of this project is to understand the fundamentals of Transformers, work with pretrained models, fine-tune language models, explore datasets and tokenizers, and build and share practical LLM applications.
